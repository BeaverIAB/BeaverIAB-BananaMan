# Sir C.J. Rhinoscooter — The Banana Man
### He's goin' bananas!!! This Toon loves giving Cogs the 'slip'!
My personal Toon, created way back in 2007, is now playable in Toontown: The Grindworks!

Inspired by the existing character, Barnacle Bessie, this Toon is unable to carry the Trap gag (lore accurate!),  instead a Banana Peel is placed in front of a random Cog every round, as the player progresses the maximum damage of the Banana Peels increases.

The game recognises the Banana Peels as valid Trap gags meaning any items the player picks up which effects that track (e.g. Detective Hat) will work with them too!

## Installation
**Windows**
1. Create a folder called `mods` in the same directory as `ToontownTheGrindworks.exe`.
2. Place `BeaverIAB-BananaMan.zip` inside the `mods` folder, do not extract `BeaverIAB-BananaMan.zip`.

**Linux**
1. Create a folder called `mods` in the same directory as `ToontownTheGrindworks.x86_64`.
2. Place `BeaverIAB-BananaMan.zip` inside the `mods` folder, do not extract `BeaverIAB-BananaMan.zip`.

**MacOS**
1. Create a folder called `mods` in the `/Applications` folder.
2. Place `BeaverIAB-BananaMan.zip` inside the `mods` folder, do not extract `BeaverIAB-BananaMan.zip`.
